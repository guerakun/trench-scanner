Trench Scanner

Screens memecoin launches for evidence and safety. Not buy signals. Not predictions.
Press Scan to start.

Grades rank evidence, not outcomes. An A-grade memecoin is still a lottery ticket. Nothing here is a buy rating, a price prediction, or financial advice.

Verdict, grade and category calls come from Jev (TypeSafe) with its probabilities shown on each card. When Jev's top choices are close, the page breaks the tie with the rules-based evidence and, if that's still unclear, takes the more cautious answer. Hard caps and hard security failures are always applied by code. Every read (heat, trend, lore, gap, phase, rebound, setup) is a heuristic or a model judgment, labeled "not a prediction".

Data: DexScreener, GeckoTerminal, RugCheck, GoPlus, Solana RPC, Bubblemaps; optional X data via your own Worker. Chains without a security checker show UNKNOWN, never a pass. Scan memory lives only in this browser.

Settings

Keys never live in this page. Jev and the X layer run through your own Cloudflare Worker, which holds the keys as secrets.
